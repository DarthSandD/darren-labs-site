Run them free, anywhere

Run them.

Ollama. No account. No fee.

# 7B
ollama pull qwen2.5:7b
ollama create darrenlabs-7b -f Modelfile.darrenlabs-7b

# 32B, give it time on CPU, use the Ollama API for first tests
ollama pull qwen3:32b
ollama create darrenlabs-32b -f Modelfile.darrenlabs-32b

Free: the method, not a public chat interface on our machine.

Use, and limits

Use them. Check them.

Use them for

  • Converting a rough CAD, MEP, or power-engineering note into a clear document
  • Checklists, and a first draft of a drawing quality note
  • A first draft for your review, correction, and approval

Do not use them for, unchecked

  • A design decision, without human judgement
  • A calculation that has not been checked
  • Anything submitted on a drawing, or to a client, without human review
