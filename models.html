How to run them.

You pull the base model, create the DarrenLabs version, and run it on your own machine. That is why it is free, and why the 32B version is slow on a CPU-only machine.

Speeds: 32GB VRAM averages. CPU: 8.8 and 1.89, measured.

Run them.

Ollama on your own machine. Free means the method and the model files, not a public chat on our machine.

# 7B
ollama pull qwen2.5:7b
ollama create darrenlabs-7b -f Modelfile.darrenlabs-7b

# 32B, give it time on CPU, use the Ollama API for first tests
ollama pull qwen3:32b
ollama create darrenlabs-32b -f Modelfile.darrenlabs-32b

Use them. Check them.

Use them for

  • Turning a rough note about a duct joint, a valve, or a cable tray into a clear checklist with items to check
  • A first draft of a drawing quality note, for an engineer to correct and approve
  • A first draft for your review, correction, and approval

Do not use them for, unchecked

  • Putting an unchecked number on a drawing
  • Sending an unchecked answer to a client
  • Any decision a licensed engineer has not reviewed
