A desktop agent that runs fully locally, with Apple liquid glass, and no remote VM to connect to.

Styx is a fork of Nous Research Hermes Agent, MIT licensed, upstream commit 25b5001. The agent, gateway, sessions, skills, cron and tools are Hermes, unchanged. What changed is the name, the amber theme, the glass materials and spring motion, and a local-only first run.

What changed, and what did not

A reskin, stated plainly.

Changed · Name and theme

Styx name, amber mark, glass.

Product name Styx, charcoal square with an amber S, amber #d97706 in place of Hermes blue, and an Apple liquid glass layer: a heavier glass sidebar, lighter glass composer, dialogs and menus, critically damped springs, press feedback on pointer down, and solid fallbacks for reduced motion and reduced transparency.

Changed · First run

Local only, no remote choice.

End users have no remote VM, so Styx never asks remote versus local on first run. It installs the Hermes backend on your own computer and runs the local gateway there. Later launches skip install entirely, because the backend is already installed. Remote connections a user already saved are not removed.

Unchanged · The agent

Same Hermes functions.

Sessions, messaging, artifacts, scheduled jobs, skills, profiles, cron, and the gateway protocol are the same as upstream. Styx is not presented as an original Darren Labs product, and its fork file names the upstream repo, commit, licence, and every changed path.

First run

How first run works.

First run needs internet once, and takes several minutes on a normal connection. A progress screen shows the stages: Prerequisites, Repository, Venv, Python deps, Config, Products, Setup, Gateway, Complete. Do not close the app while it installs. When it finishes, the app opens to provider setup. Add your own model provider key in Settings, then chat. No provider key ships with Styx, and no prompt is sent anywhere until you configure one.

Verified in an isolated test home on 4 November 2026: gateway ready at a local loopback endpoint, runtime protocol 1, code 25b5001 matching the desktop build, and the app reaching provider setup. Chat with a model was not run in that test, because no provider key was set, and that limit is stated here rather than hidden.

Honest limits

What Styx is not yet.

  • Linux only in this release. Windows and macOS builds are not verified.
  • Chat needs a provider key you supply. Without one, you can open the app and reach provider setup, but you cannot chat with a model.
  • First install is slow on a slow connection, and a slow first install can outlast the first connection attempt. Click Retry, which reconnects without reinstalling what already finished.
  • Styx shares the agent home at ~/.hermes with Hermes Agent itself, by design, because the backend is the same Hermes gateway.
